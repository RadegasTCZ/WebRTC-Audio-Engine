# Security policy

WebRTC Audio Engine runs inside the Windows audio engine (audiodg) and its installer runs with administrator
rights, so security problems are taken seriously.

## Reporting a vulnerability
Please do **not** open a public issue. Report it privately through this repository's
**Security** tab > **Report a vulnerability** on GitHub.

Include the version you installed, your Windows build, and the steps to reproduce. You will get a reply as soon
as possible; this is a one-person project, so please allow a few days.

## Supported versions
Only the latest official release, published on this repository's Releases page, receives fixes. Builds from
any other source are not supported.
